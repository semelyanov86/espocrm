- `uninstall --purge` + `install` в этой сессии не повторялись (правило автоматического режима); чистую установку дал
  backup установки этапа 02 того же релиза EspoCRM. Повторить полный цикл с установкой — на этапе 09 (Ansible) или с
  разрешения владельца: `task stand:uninstall -- --yes --purge` → `task stand:install` → шаги 5–10.

- Записи разговоров на стенде раскладывает импорт (`--recordings place`); на production — только проверка (`verify`).

  UI-фикстура ключа безопасности для проверки YubiKey владельца создана заново после итогового прогона (`TASKS.md`).
